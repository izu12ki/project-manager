Backlog の課題 CSV を取り込むとき、番号を Backlog のキーの番号のままにするようにしました（`PROJ-12` は #12）。これまでは続きから詰めて振っていたので、Backlog で削除した課題があると番号がずれ、本文や Slack に残る `PROJ-12` が別の課題を指していました。同じ番号の課題が既にあるときと、キーの接頭辞がプロジェクトのキーと違うときだけ、最大の番号の続きから振り、確認画面にどの課題が何番になるかを出します。

課題一覧のキーワードと API の `q` で、取り込んだ課題を元の Backlog のキー（`PROJ-12`）でも探せるようにしました。
