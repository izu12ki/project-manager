パスワードのハッシュ化の重い計算（PBKDF2-SHA256、60 万回）をブラウザで行うようにしました。サーバーは受け取った値を SHA-256 で照合するだけになり、ログインなどの CPU 時間が減ります（Workers の無料プランで動かすための準備）。

- ログイン・初期セットアップ・招待の受諾・パスワードの変更と再設定には JavaScript が必要です。また、https://（手元では localhost）で開く必要があります。
- 0.3 までに保存したパスワード（better-auth の既定の scrypt）では、ログインできなくなります。このリリースではデータベースを D1 に変え、Turso のデータは引き継がないので、ふつうは影響しません。データを自分で移した場合は、ログイン画面の「パスワードをお忘れですか？」から再設定してください（メールの送信の設定が要ります）。
