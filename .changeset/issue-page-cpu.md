Workers の無料プラン（1 リクエストの CPU 時間 10ms）に収まりやすくするため、サーバーの処理を減らしました。

- 課題の詳細画面は、コメント・編集履歴・添付ファイルをブラウザから別のリクエストで読み込むようにしました。これまでは課題を開くリクエストでコメントの Markdown をすべて変換していたので、コメントの多い課題では CPU 時間が 10ms を大きく超えていました（手元の計測でコメント 40 件の課題が 24ms → 10ms）。課題を開いた直後は、コメント欄に「読み込み中…」と出ます。
- 課題一覧と「自分の課題」は、表示する列だけを読むようにしました（画面の HTML が 1 割ほど小さくなります）。
- プロジェクトの画面・課題一覧（絞り込みなし）・課題の詳細の問い合わせは、SQL の組み立てを Worker の中で使い回すようにしました。
