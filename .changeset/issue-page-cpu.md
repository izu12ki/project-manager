Workers の無料プラン（1 リクエストの CPU 時間 10ms）に収まりやすくするため、サーバーの処理を減らしました。

- 課題の詳細画面は、コメント・編集履歴・添付ファイルをブラウザから別のリクエストで読み込み、コメントの Markdown もブラウザで HTML にするようにしました。これまでは課題を開くリクエストでコメントの Markdown をすべて変換していたので、コメントの多い課題では CPU 時間が 10ms を大きく超えていました（手元の計測でコメント 40 件の課題が 24ms → 課題 7.7ms とコメント 4.5ms の 2 回）。課題を開いた直後は、コメント欄に「読み込み中…」と出ます。
- 課題一覧は 1 ページ 25 件にしました。画面の HTML の大きさに比例してサーバーの CPU 時間がかかるためです。
- 課題一覧と「自分の課題」は、表示する列だけを読むようにしました（画面の HTML が 1 割ほど小さくなります）。
- ログイン状態の確認に使う認証の設定を、リクエストごとに作り直さず、Worker の起動時に 1 回だけ作るようにしました。
- プロジェクトの一覧（どの画面でも読む）・プロジェクトの画面・課題一覧（絞り込みなし）・課題の詳細の問い合わせは、SQL の組み立てを Worker の中で使い回すようにしました。
