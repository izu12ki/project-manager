```bash
mise install
pnpm install
cd apps/web
cp .dev.vars.example .dev.vars   # BETTER_AUTH_SECRET を書き換える
pnpm db:migrate:local            # ローカルの D1 にテーブルを作る
pnpm dev                         # http://localhost:5173
```

`mise install` は Node.js と pnpm を入れます。最初に一度実行してください。DB はローカルの D1（wrangler が `.wrangler/state` に作る SQLite）なので、別のサーバーを起動する必要はありません。

## テスト

```bash
pnpm test:unit --run   # services の単体テスト（インメモリ DB。D1 の制約を再現する）
pnpm test:e2e          # Playwright（空のローカル D1 と wrangler dev を自動で用意）
pnpm lint && pnpm check
```

## スキーマを変えたとき

```bash
pnpm db:generate --name <変更内容>
pnpm db:migrate:local
```

D1 にはトランザクションが使えない、1 つのクエリのバインド変数が 100 個まで、などの制約があります。コードを書く前に [CONTRIBUTING.md の「D1 の制約」](https://github.com/izu12ki/project-manager/blob/main/CONTRIBUTING.md#d1-の制約)を読んでください。

## CPU 時間を測る

Workers の無料プランは 1 リクエストの CPU 時間が 10ms までです。画面や services を変えたら、手元の wrangler dev でリクエストごとの CPU 時間と D1 の往復回数を測れます。

```bash
cd apps/web
pnpm perf:server data.sql      # ビルドして http://localhost:4174 で起動。data.sql を渡すと DB を作り直して流し込む
# 別のシェルで
node scripts/cpu-profile.ts --email you@example.com --password '...' / /projects/ACME /projects/ACME/issues/1
```

```
   CPU  D1 往復  status  route
  4.12ms       4     200  /projects/ACME
```

- 各 route を 5 回温めてから 40 回実行し、V8 のプロファイラで取った CPU 時間の平均を出します。`--self`・`--incl` で関数ごとの内訳、`--save <prefix>` で Chrome DevTools で開ける `.cpuprofile` を書きます。`LOGIN` を route に書くとログインそのものを測ります。
- 応答は圧縮させずに測ります（手元の workerd は gzip の圧縮を CPU 時間に含めますが、本番ではエッジが圧縮するので含まれません）。
- 手元は本番より速く、本番の CPU 時間は手元の 1.5〜2 倍ほどです（2026-11 の計測）。手元で 5ms 以下を目安にしてください。
- D1 は 1 往復ごとに CPU 時間がかかります（手元で 0.25〜0.4ms）。1 つの画面の読み取りは 1 回の batch にまとめ、単体テストでは `roundTrips(db)`（`test-utils.ts`）で往復の回数を確かめます。読み取りの batch は `ctx.readBatch` で送ると、同じリクエストで同時に出た batch（レイアウトとページの load、remote query）が 1 往復にまとまります。書き込みは `ctx.db.batch` で送ります。

### 無料プランで確かめる

Cloudflare のアカウントに検証用の Worker（`project-manager-free-check`）と専用の D1・R2 を作り、E2E テストをその Worker に向けて流して、route ごとの CPU 時間と上限超過のエラーの有無を出します。本番の Worker と D1 には触れません。

```bash
cd apps/web
CLOUDFLARE_ACCOUNT_ID=<アカウント ID> bash scripts/free-plan-check.sh
```

Paid プランのアカウントでは CPU 時間の上限を 10ms に設定した Worker を、無料プランのアカウントでは上限を付けずに（無料プランの 10ms がそのまま効く）出します。終わると Worker は消します（`--keep` で残す、`--delete` で D1・R2 も消す）。E2E のアカウントのパスワードはリポジトリにあるので、Worker を残したままにしないでください。
