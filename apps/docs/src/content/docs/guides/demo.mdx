公開デモで、実際の画面を見られます。プロジェクト、メンバー、課題はすべて架空のものです。

| 項目           | 値                                                                                     |
| -------------- | -------------------------------------------------------------------------------------- |
| URL            | [https://project-manager.hirano-i.workers.dev](https://project-manager.hirano-i.workers.dev) |
| メールアドレス | `demo@example.com`                                                                     |
| パスワード     | `pm-demo-2026`                                                                         |

<Aside type="caution" title="デモは閲覧専用です">
デモのアカウントは「閲覧者」ロールです（[権限](/reference/permissions/)）。課題の起票・編集、ステータスの変更、コメントとリアクション、ファイルの添付、カンバンやタイムラインのドラッグはできません。これらの操作は、下の「デモでは試せない操作」の画面イメージで確認してください。
</Aside>

## デモでは試せない操作

デモの閲覧者ではできない操作を、管理者・メンバー・ゲストのアカウントで撮影しました。

### 課題の起票

顧客（ゲスト）も課題を起票できます。

![新規課題ボタンから種別とタイトルを入力して起票する様子](/screenshots/create-issue.gif)

### カンバンでのステータス変更

カードをドラッグして、別の列（ステータス）に移します。

![カンバンでカードを「進行中」から「レビュー」の列へドラッグする様子](/screenshots/board-drag.gif)

### タイムラインでの日程変更

バーの端をドラッグして期限を延ばします。中央をドラッグすると、開始日と期限をまとめてずらします（[タイムライン](/guides/timeline/)）。

![タイムラインでバーの右端をドラッグして期限を 2 日延ばす様子](/screenshots/timeline-drag.gif)

### コメント・メンション・リアクション

`@` で始めるとメンションの候補が出ます。コメントには絵文字でリアクションできます。

![コメントにリアクションを付け、メンション付きのコメントを投稿する様子](/screenshots/comment-reaction.gif)

### ファイルの添付

画像は本文に表示されます。貼り付けやドロップでも添付できます。

![コメント欄で画像を添付して投稿する様子](/screenshots/attach-image.gif)

### 子課題の追加

課題の詳細から、親課題を指定した状態で子課題を起票できます。

![課題の詳細の「子課題を追加」から子課題を起票する様子](/screenshots/add-subtask.gif)
