---

import { Steps } from '@astrojs/starlight/components';

始める前に、[必要なもの](/guides/requirements/)をそろえてください。

<Steps>

1. ソースを取得してツールを入れる

   ```bash
   git clone <このリポジトリの URL> project-manager
   cd project-manager
   git checkout "$(git tag --list 'web@*' --sort=-version:refname | head -n 1)"  # 最新のリリース
   mise install
   pnpm install
   ```

2. Cloudflare にログインして、データベース（D1）を作る

   ```bash
   cd apps/web
   pnpm exec wrangler login
   pnpm exec wrangler d1 create project-manager --location apac   # --location は利用者に近い地域（日本なら apac）
   pnpm db:migrate:remote                                         # テーブルを作る
   ```

   D1 は `apps/web/wrangler.jsonc` の `database_name`（`project-manager`）で結び付くので、表示される `database_id` を設定ファイルに書く必要はありません。設定ファイルへの追加を聞かれたら「いいえ」を選びます。別の名前で作る場合は、`database_name` も同じ名前に変えてください。

3. シークレットを登録する

   ```bash
   pnpm exec wrangler secret put BETTER_AUTH_SECRET   # `openssl rand -base64 32` の出力
   pnpm exec wrangler secret put BETTER_AUTH_URL      # 公開 URL。例: https://project-manager.<サブドメイン>.workers.dev
   ```

   添付ファイルを保存する R2 バケットを作ります（名前は `apps/web/wrangler.jsonc` の `bucket_name` と同じにします）。

   ```bash
   pnpm exec wrangler r2 bucket create project-manager-attachments
   ```

   メールを送る場合は `MAIL_PROVIDER` / `MAIL_FROM`（SMTP2GO・Resend では `MAIL_API_KEY` も）を登録します（[メール送信の設定](/guides/mail/)）。登録しなければ招待リンクは画面に表示されるので、手で相手に渡せます。

   :::note[初回のデプロイ前]
   初回はまだ Worker が無いので、`secret put` が Worker の作成を確認してきたら「はい」を選びます。`BETTER_AUTH_URL` が分からない場合は、先に手順 4 でデプロイして URL を確認し、登録後にもう一度デプロイします。
   :::

4. デプロイする

   ```bash
   pnpm deploy
   ```

   表示された URL を開くと初期セットアップ画面（`/setup`）になります。最初の管理者アカウントを作成してください。

</Steps>

## 独自ドメインを使う

Cloudflare ダッシュボードの Workers の「Settings → Domains & Routes」で設定し、`BETTER_AUTH_URL` をその URL に変えて再デプロイします。
