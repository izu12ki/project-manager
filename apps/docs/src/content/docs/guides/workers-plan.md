title: Workers のプランと上限
description: Workers の無料プランで動かすときの上限と、10ms を超える操作、D1 の読み取り行数の目安
---

小規模なチームなら、Workers の無料プランで動きます。無料プランの主な上限は次のとおりです（2026-11 時点。最新の値は Cloudflare の [Workers](https://developers.cloudflare.com/workers/platform/limits/)・[D1](https://developers.cloudflare.com/d1/platform/limits/) の上限のページで確認してください）。

| 上限 | 無料プラン |
|---|---|
| リクエスト数 | 1 日 10 万回 |
| 1 リクエストの CPU 時間 | 10ms |
| D1 の容量 | 1 つの DB で 500MB |
| D1 の読み書き | 1 日に読み取り 500 万行、書き込み 10 万行（アカウントのすべての DB の合計） |

課題の多いプロジェクトを大勢で使うと、先に届きやすいのは D1 の読み取りです（[D1 の読み取り](#d1-の読み取り)）。

## CPU 時間

課題が数千件あるプロジェクト（Backlog から移したものなど）でも表示の CPU 時間が増え続けないよう、課題一覧と「自分の課題」は 1 ページ 25 件、カンバンは最初に 1 列 25 件（完了の列は最近完了にしたものから）を出して下へスクロールすると 25 件ずつ読み込み（1 列 500 件まで。列の件数は 100 件を超えると「100+」と出します）、タイムラインは表示を始める日より前に終わった完了課題を出さず、行を 300 件までにしています。

### 10ms を超える操作

本番（無料プラン）で計測した CPU 時間です（2026-11、中央値）。課題 100 件と 3,000 件のプロジェクトで測りました。

| 操作 | CPU 時間（課題 100 件 / 3,000 件） |
|---|---|
| 画面をリンク・ブックマーク・再読み込みから開いた時（サーバーで画面を組み立てる） | 課題一覧 13 / 10ms、課題の詳細 11 / 15ms、カンバン 12 / 24ms、タイムライン 19 / 33ms、自分の課題 10 / 11ms |
| 課題の多いプロジェクトでのアプリ内の移動 | 3,000 件のカンバン 14ms、タイムライン 19ms（100 件なら 6ms、8ms） |
| Backlog からの取り込み | 数十 ms（[Backlog からの移行](/guides/backlog-import/)） |
| 一括起票・一括更新の API | 件数が多いと超えることがある |
| 起動したばかりの Worker への最初の数回のリクエスト | 数十〜100ms ほど |

- 同じリクエストでも値はばらつき、ときどき 40〜80ms になります。
- カンバンの値は、列ごとに 25 件ずつ読み込むようにする前の計測です。手元の計測では、3,000 件のカンバンの CPU 時間はその後 4 割ほど下がっています。

### 上限を超えると

Cloudflare は 10ms を超えるリクエストをある程度許しますが、超え続けると処理を打ち切ることがあります（1102 エラー、「Worker exceeded resource limits」）。無料プランのアカウントで、E2E テストの全操作（ログイン、課題の起票・編集、コメント、招待、Backlog からの取り込み、パスワードの再設定など）を流した確認と、上の計測（画面を開く操作 約 800 回）では、1102 エラーは出ませんでした（2026-11）。

## D1 の読み取り

D1 は、SQL が読んだ行数で数えます（画面に出した件数ではありません）。画面を 1 回開くと、そのプロジェクトの課題の数に応じて読み取りが増えます。「自分の課題」は、プロジェクトの課題の数ではなく、自分が担当している（または登録した）課題の数に応じて増えます。

上限を超えると、その日の 9:00（日本時間。0:00 UTC）まで、DB を使う操作がすべてエラーになります（ログインもできません）。同じアカウントのほかの D1 データベースの読み取りも合算されます。使った行数は、Cloudflare のダッシュボードの D1 の画面で確認できます。

書き込み（1 日 10 万行）は、ふつうの使い方なら読み取りより先に上限に届くことはありません。

## Workers Paid プランにする目安

次のどれかに当てはまるなら、Workers Paid プラン（月額 5 ドル〜）にしてください。Paid では、D1 の読み取りは月 250 億行、書き込みは月 5,000 万行まで料金に含まれ、1 リクエストの CPU 時間の上限も 10ms ではなくなります。

- 課題の多いプロジェクトを大勢で使い、D1 の読み取りが 1 日 500 万行に近い
- 利用者が多く、1 日のリクエスト数が 10 万回に近い
- 「Worker exceeded resource limits」（1102 エラー）が出る
