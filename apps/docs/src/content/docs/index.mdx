## できること

- **課題管理** — 課題番号（`ACME-12` 形式）、ステータス、優先度、担当者、期限
- **カンバン** — ドラッグで列の移動と並び替え
- **コメント** — Markdown で書ける
- **顧客ゲスト** — 顧客を「ゲスト」として招待し、参加しているプロジェクトだけを見せる。ゲストは起票とコメント、自分が起票した課題の編集、自分が担当の課題のステータス変更ができる
- **通知** — 担当の割り当て、ステータスの変更、コメント、`@` メンションをアプリ内で通知
- **Slack 連携** — プロジェクトの出来事を Slack のチャンネルに投稿
- **招待メール / パスワードリセット** — SMTP2GO または Resend の無料枠で送信。メール設定なしでも招待リンクを手渡しできる

利用者ごとに自分の Cloudflare アカウントへデプロイして使います（SaaS としての提供はありません）。Cloudflare は Workers Paid プラン（月額 5 ドル〜）が必要です。
