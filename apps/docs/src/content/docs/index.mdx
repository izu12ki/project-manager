## できること

- **課題管理** — 課題番号（`ACME-12` 形式）、ステータス・種別（プロジェクトごとに変更できる）、優先度、複数の担当者、開始日と期限、カテゴリー、マイルストーン、1 階層のサブタスク。キーワードや条件で絞り込めて、編集履歴では説明文の差分も見られる
- **カンバン** — ドラッグで列の移動と並び替え
- **タイムライン** — 課題を開始日から期限までのバーで並べ、ドラッグで日程を変える。土日と日本の祝日は灰色で表示（[タイムライン](/guides/timeline/)）
- **エディタ** — 課題の説明とコメントを見たまま編集できる Markdown エディタ。表、ファイルの貼り付け・ドロップ、`@` メンション
- **コメント** — 絵文字でリアクションできる。カスタム絵文字も登録できる
- **添付ファイル** — Cloudflare R2 に保存
- **顧客ゲスト** — 顧客を「ゲスト」として招待し、参加しているプロジェクトだけを見せる。ゲストは起票とコメント、自分が起票した課題の編集、自分が担当の課題のステータス変更ができる
- **通知** — 担当の割り当て、ステータスの変更、コメント、`@` メンションをアプリ内で通知
- **Slack 連携** — 自分に関わる通知を Slack の DM で受け取る
- **表示** — ダークモード、文字の大きさの切り替え
- **REST API** — 管理者が発行する API キーで、課題の一括起票・一括修正やスケジュールの作成ができる。Claude Code 用の Skill を同梱
- **招待メール / パスワードリセット** — Cloudflare Email Sending（Workers Paid プランに月 3,000 通まで含まれる）、SMTP2GO、Resend のどれかで送信。メール設定なしでも招待リンクを手渡しできる

利用者ごとに自分の Cloudflare アカウントへデプロイして使います（SaaS としての提供はありません）。Cloudflare は Workers Paid プラン（月額 5 ドル〜）が必要です。
