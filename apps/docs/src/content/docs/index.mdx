## できること

<CardGrid>
	<Card title="課題管理" icon="list-format">
		課題番号（`ACME-12` 形式）、ステータス・種別（プロジェクトごとに変更できる）、優先度、複数の担当者、開始日と期限、複数のカテゴリー、マイルストーン、1 階層のサブタスク。タイトル・本文・コメントのキーワードや条件で絞り込めて、編集履歴では説明文の差分も見られます。
	</Card>
	<Card title="カンバン" icon="puzzle">
		ドラッグで列の移動と並び替えができます。
	</Card>
	<Card title="タイムライン" icon="analytics">
		課題を開始日から期限までのバーで並べ、ドラッグで日程を変えます。土日と日本の祝日は灰色で表示します（[タイムライン](/guides/timeline/)）。
	</Card>
	<Card title="エディタ" icon="pencil">
		課題の説明とコメントを見たまま編集できる Markdown エディタ。表、ファイルの貼り付け・ドロップ、`@` メンションに対応しています。本文やコメントに書いた課題キー（`PROJ-12`）は、その課題へのリンクになります。
	</Card>
	<Card title="コメント" icon="comment">
		絵文字でリアクションできます。カスタム絵文字も登録できます。
	</Card>
	<Card title="添付ファイル" icon="document">
		Cloudflare R2 に保存します。
	</Card>
	<Card title="顧客ゲスト・閲覧者" icon="padlock">
		顧客を「ゲスト」として招待し、参加しているプロジェクトだけを見せます。ゲストは課題の起票・編集とコメントができます（削除はできません）。見せるだけの相手は「閲覧者」として招待すると、起票・編集・コメント・添付が一切できません（[権限](/reference/permissions/)）。
	</Card>
	<Card title="通知" icon="information">
		担当の割り当て、ステータスの変更、コメント、`@` メンションをアプリ内で通知します。
	</Card>
	<Card title="Slack 連携" icon="slack">
		自分に関わる通知を Slack の DM で受け取れます（[Slack 連携](/guides/slack/)）。
	</Card>
	<Card title="表示" icon="moon">
		ダークモードと、文字の大きさの切り替えに対応しています。
	</Card>
	<Card title="REST API" icon="setting">
		管理者が発行する API キーで、課題の一括起票・一括修正やスケジュールの作成ができます。Claude Code 用の Skill を同梱しています。
	</Card>
	<Card title="招待メール / パスワードリセット" icon="email">
		SMTP2GO、Resend、Cloudflare Email Sending（Workers Paid プランのみ）のどれかで送信します。メール設定なしでも招待リンクを手渡しできます（[メール送信の設定](/guides/mail/)）。
	</Card>
</CardGrid>

## 使い始める

利用者ごとに自分の Cloudflare アカウントへデプロイして使います（SaaS としての提供はありません）。小規模なチームなら Cloudflare の Workers の無料プランで動きます。
