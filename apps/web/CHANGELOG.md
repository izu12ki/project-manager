- fc014ed: データベースを Turso から Cloudflare D1 に変えました。Turso のアカウントは要らなくなり、Cloudflare のアカウントだけで動きます。
  
  - 新しく導入するときは、ドキュメントの「デプロイ手順」に沿って `wrangler d1 create` で D1 を作り、`pnpm db:migrate:remote` でテーブルを作ります。
  - マイグレーションのコマンドは `pnpm db:migrate` から `pnpm db:migrate:remote` に変わりました。シークレットの `TURSO_DATABASE_URL` と `TURSO_AUTH_TOKEN` は使わなくなりました。
  - Turso のデータを D1 へ移す手順とスクリプトは用意していません。

## 0.3.4

### Patch Changes

- 52206f0: 課題一覧に「開始日」「登録日」「更新日」の列を追加し、列見出しを押すと並べ替えられるようにしました。
  
  - 並べ替えられる列は キー・開始日・期限・登録日・更新日 です。同じ列をもう一度押すと昇順と降順が入れ替わります。最初に押したときは、開始日・期限は近い順、登録日・更新日は新しい順になります。

  - 課題の更新日時は、項目を変えたときに加えて、コメントを投稿・編集したときにも進むようにしました（コメントの削除とリアクションでは変わりません）。REST API の `updatedAt` も同じです。
