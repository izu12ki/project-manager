# web

## 0.2.0

### Minor Changes

- 55cfc8c: Backlog の課題 CSV から、課題とコメントをプロジェクトに取り込めるようにしました。
  
  - 更新時に DB マイグレーション（`pnpm db:migrate`）が必要です（課題に取り込み元のキーの列を足し、削除済みのカテゴリーが課題に残っていれば外します）。
  - 取り込んだ課題の登録者・コメントの投稿者に対応する人がいないときのため、ログインできない「不明なユーザー」を作ります。ユーザー一覧には出ません。
- 502e5a3: プロジェクト設定でアイコン画像（PNG・JPEG・GIF・WebP、1MB 以下）を設定できるようにしました。設定すると、文字のアイコンの代わりにサイドバー・プロジェクト一覧・プロジェクトの見出しに出します。サイドバーのプロジェクトは、名前を太字で、その下にキーを薄く出すようにしました。新規プロジェクトの作成画面からは説明欄を外しました（説明は設定画面で入れられます）。
  
  - 更新時に DB マイグレーション（`pnpm db:migrate`）が必要です（プロジェクトにアイコン画像の列を足します）。

### Patch Changes

- 0666b8d: Backlog からの取り込みを直しました。
  
  - ユーザー CSV: 招待メールを送れなかった人を、人数だけでなく名前とメールアドレスで結果に出すようにしました。途中で 1 人の招待に失敗しても、残りの人を招待し、作れた招待のメールを送ります（招待できなかった人も結果に出ます）。取り込み中に画面を閉じても、招待メールの送信が止まりにくくなりました。
  - ユーザー CSV: 確認画面の見出しのチェックで、取り込める人をまとめて選んだり外したりできるようにしました。
  - 課題 CSV: 件名が 200 文字を超える課題を取り込まずにいたのを、200 文字に切り詰めて取り込むようにしました。元の件名は本文の末尾に残します。
  - 課題 CSV: 取り込みと同時に同じ名前の種別・カテゴリー・マイルストーンが追加されて失敗したとき、その旨を伝えるようにしました。
  - 「不明なユーザー」を、ユーザー管理の操作（有効化・無効化・ロール変更）の対象にできないようにしました。

## 0.1.0

### Minor Changes

- 76e84a6: Backlog のユーザー CSV から、まとめて招待できるようにしました。プロジェクトキーに Backlog と同じ形式（アンダースコア、25 文字まで）を使えるようにしました。
  
  - 更新時に DB マイグレーション（`pnpm db:migrate`）が必要です（招待に名前の列を足します）。
  - 管理者のロールでは、参加プロジェクトを選ばずに招待できるようにしました。
- 20a2772: 課題にカテゴリーを複数付けられるようにしました。一覧とカンバンには付いているカテゴリーをすべて表示します。
  
  - 更新時に DB マイグレーション（`pnpm db:migrate`）が必要です。既存の課題のカテゴリーは自動で移ります。
  - REST API の課題の項目 `categoryId` を `categoryIds`（ID の配列）に変えました。`categoryId` を送ると 400 になります。一覧の絞り込みクエリ `categoryId` は変わりません。
