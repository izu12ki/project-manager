# タイムライン（ガントチャート） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** プロジェクトに「タイムライン」タブを追加し、課題を開始日〜期限のバーとして表示し、ドラッグで日付を変更できるようにする。

**Architecture:** 日付計算・祝日判定・グループ化はフレームワーク非依存の純関数（`src/lib/timeline.ts`、`src/lib/holidays.ts`）にまとめ、Vitest で固める。サーバーは既存の `issues` サービスに `listTimeline` を足し、日付の更新は既存の `updateIssue` を remote `command` から呼ぶ。画面はボードと同じく remote `query` で読み込み、楽観的に更新して失敗時に戻す。DB マイグレーションはない。

**Tech Stack:** SvelteKit 3（remote functions、experimental async）、Svelte 5 runes、Drizzle ORM v1 rc、Valibot、Vitest、Playwright、Astro Starlight。

**Spec:** `docs/superpowers/specs/2026-10-15-timeline-design.md`

## Global Constraints

- DB マイグレーションを追加しない（`issue.startDate` / `dueDate` / `milestoneId`、`milestone.releaseDate` は既存）。
- 新しい依存パッケージを追加しない（祝日パッケージは devDependencies にも入れない）。
- 日付は `'YYYY-MM-DD'` 文字列で扱い、計算は UTC。タイムゾーン・夏時間の影響を受けないこと。
- 「今日」は既存の `todayJst()`（`$lib/labels`）。
- 日付の保存は必ず `updateIssue` を通す（`issue:edit` 権限、`assertDateRange`、アーカイブ拒否をそのまま使う）。新しい権限 Action は追加しない。
- グリッド内のクラス名に `label` を使わない（`layout.css` のグローバルな `.label` と衝突する）。行の左列は `.name`。
- UI 文言は日本語。既存の CSS クラス（`btn` `btn-outline` `btn-primary` `btn-sm` `select` `field` `label` `icon-btn` `empty` `mono` `hint`）と CSS 変数（`--border` `--card` `--muted-foreground` `--c-gray` `--c-amber` `--primary` `--foreground`）を使う。
- `.svelte` を編集したら Svelte MCP の `svelte-autofixer` で確認し、`pnpm check` と `pnpm lint` を通す（作業ディレクトリ `apps/web`）。
- コミットメッセージは `feat(web): ...` / `test(web): ...` / `docs: ...` 形式。作業ブランチは `feat/timeline`（作成済み）。

## Review Focus

1. 月末・年末をまたぐドラッグ（例: 12/30–12/31 を 2 日右へ）で日付が正しく繰り上がる → Task 2 の `applyDrag` テストに含める。
2. 伸縮で開始日と期限が逆転しそうな操作（左端を期限より右へ）→ 期限と同日で止まる → Task 2 のテストに含める。
3. ドラッグ後に指を離したとき課題詳細へ遷移してしまう（クリック扱い）→ 遷移しない → Task 5 の E2E で URL が変わらないことを確認する。
4. URL クエリが不正（`from=abc`、`group=x`、`from=2026-02-30`）→ 既定値で表示し、例外にしない → Task 2 の `parseView` テストに含める。
5. ゲスト・アーカイブ済みプロジェクトでは他人の課題のバーを動かせない → Task 3 の `canEdit` テストと Task 5 の E2E に含める。

/** 内閣府 syukujitsu.csv（UTF-8 に変換済み）: 'YYYY-MM-DD' → 名称 */
function loadCsv(): Map<string, string> {
	const text = readFileSync(new URL('./testdata/syukujitsu.csv', import.meta.url), 'utf8');
	return new Map(
		text
			.trim()
			.split('\n')
			.slice(1)
			.map((line) => {
				const [date, name] = line.split(',');
				const [y, m, d] = date.split('/').map(Number);
				return [`${y}-${String(m).padStart(2, '0')}-${String(d).padStart(2, '0')}`, name];
			})
	);
}

/** 自前の名称を CSV の表記に寄せる（CSV は振替休日・国民の休日をどちらも「休日」と書く） */
function asCsvName(date: string, name: string): string {
	if (name === '振替休日' || name === '国民の休日') return '休日';
	if (name === '即位の日' || (name === '即位礼正殿の儀' && date.startsWith('2019-'))) {
		return '休日（祝日扱い）';
	}
	return name;
}

		const actual = new Map<string, string>();

/**
 * 日本の祝日（国民の祝日・振替休日・国民の休日）を規則から計算する。
 *
 * 次の実装を TypeScript に移植し、日付を 'YYYY-MM-DD' と UTC だけで扱うようにしたもの。
 * japanese-holidays-js (https://github.com/osamutake/japanese-holidays-js)
 * Copyright (c) 2016 Osamu Takeuchi <osamu@big.jp> — The MIT License (MIT)
 *
 * 祝日法の改正で祝日が増えたり変わったりしたら RULES を直す。
 * 正しさは内閣府の syukujitsu.csv と突き合わせて確認している（holidays.test.ts）。
 */

const DAY_MS = 86_400_000;

function iso(ms: number): string {
	return new Date(ms).toISOString().slice(0, 10);
}
function ymd(y: number, m: number, d: number): string {
	return iso(Date.UTC(y, m - 1, d));
}
function shift(date: string, days: number): string {
	return iso(Date.parse(date) + days * DAY_MS);
}
function weekday(date: string): number {
	return new Date(date).getUTCDay();
}

const fixed = (m: number, d: number) => (y: number) => ymd(y, m, d);

/** m 月の第 nth 月曜 */
const happyMonday = (m: number, nth: number) => (y: number) => {
	const dow = new Date(Date.UTC(y, m - 1, 1)).getUTCDay();
	return ymd(y, m, 1 + ((8 - dow) % 7) + (nth - 1) * 7);
};

/** 春分・秋分の瞬間（ms）を日本時間の日付にする */
const jstDate = (ms: number) => iso(ms + 9 * 3_600_000);
const shunbun = (y: number) => jstDate(-655_866_700_000 + 31_556_940_400 * (y - 1949));
/** 近似式がずれる年の補正 */
const SHUBUN_FIX: Record<number, number> = { 2074: 23 };
const shubun = (y: number) =>
	SHUBUN_FIX[y]
		? ymd(y, 9, SHUBUN_FIX[y])
		: jstDate(-671_316_910_000 + 31_556_910_000 * (y - 1948));

type Rule = readonly [name: string, date: (y: number) => string, from: number, to?: number];

/** 名前・日付の求め方・施行年・廃止年。1 回限りのものは from = to。名前は内閣府 CSV の表記に合わせる */
const RULES: readonly Rule[] = [
	['元日', fixed(1, 1), 1949],
	['成人の日', fixed(1, 15), 1949, 1999],
	['成人の日', happyMonday(1, 2), 2000],
	['建国記念の日', fixed(2, 11), 1967],
	['天皇誕生日', fixed(2, 23), 2020],
	['大喪の礼', fixed(2, 24), 1989, 1989],
	['春分の日', shunbun, 1949],
	['結婚の儀', fixed(4, 10), 1959, 1959],
	['天皇誕生日', fixed(4, 29), 1949, 1988],
	['みどりの日', fixed(4, 29), 1989, 2006],
	['昭和の日', fixed(4, 29), 2007],
	['即位の日', fixed(5, 1), 2019, 2019],
	['憲法記念日', fixed(5, 3), 1949],
	['みどりの日', fixed(5, 4), 2007],
	['こどもの日', fixed(5, 5), 1949],
	['結婚の儀', fixed(6, 9), 1993, 1993],
	['海の日', fixed(7, 20), 1996, 2002],
	['海の日', happyMonday(7, 3), 2003, 2019],
	['海の日', fixed(7, 23), 2020, 2020],
	['海の日', fixed(7, 22), 2021, 2021],
	['海の日', happyMonday(7, 3), 2022],
	['山の日', fixed(8, 11), 2016, 2019],
	['山の日', fixed(8, 10), 2020, 2020],
	['山の日', fixed(8, 8), 2021, 2021],
	['山の日', fixed(8, 11), 2022],
	['敬老の日', fixed(9, 15), 1966, 2002],
	['敬老の日', happyMonday(9, 3), 2003],
	['秋分の日', shubun, 1948],
	['体育の日', fixed(10, 10), 1966, 1999],
	['体育の日', happyMonday(10, 2), 2000, 2018],
	['体育の日（スポーツの日）', happyMonday(10, 2), 2019, 2019],
	['スポーツの日', fixed(7, 24), 2020, 2020],
	['スポーツの日', fixed(7, 23), 2021, 2021],
	['スポーツの日', happyMonday(10, 2), 2022],
	['即位礼正殿の儀', fixed(10, 22), 2019, 2019],
	['文化の日', fixed(11, 3), 1948],
	['即位礼正殿の儀', fixed(11, 12), 1990, 1990],
	['勤労感謝の日', fixed(11, 23), 1948],
	['天皇誕生日', fixed(12, 23), 1989, 2018]
];

function compute(year: number): Map<string, string> {
	const base = new Map<string, string>();
	for (const [name, date, from, to] of RULES) {
		if (year < from || (to !== undefined && year > to)) continue;
		base.set(date(year), name);
	}
	// 国民の休日: 祝日に挟まれた日（日曜・月曜は除く。月曜は振替休日になるため）
	if (year >= 1988) {
		for (const d of [...base.keys()]) {
			const next = shift(d, 1);
			const dow = weekday(next);
			if (base.has(shift(d, 2)) && !base.has(next) && dow !== 0 && dow !== 1) {
				base.set(next, '国民の休日');
			}
		}
	}
	// 振替休日: 日曜の祝日の後の、祝日でない最初の日。2007 年より前は翌日が祝日なら振り替えない
	const result = new Map(base);
	for (const d of base.keys()) {
		if (d < '1973-04-29' || weekday(d) !== 0) continue;
		let f = shift(d, 1);
		if (base.has(f)) {
			if (d < '2007-01-01') continue;
			while (base.has(f)) f = shift(f, 1);
		}
		result.set(f, '振替休日');
	}
	return new Map([...result].sort(([a], [b]) => (a < b ? -1 : 1)));
}

const cache = new Map<number, Map<string, string>>();

/** その年の祝日（'YYYY-MM-DD' → 名前）。日付順 */
export function holidaysOf(year: number): Map<string, string> {
	let m = cache.get(year);
	if (!m) cache.set(year, (m = compute(year)));
	return m;
}

/** 'YYYY-MM-DD' が祝日ならその名前 */
export function holidayName(date: string): string | undefined {
	return holidaysOf(Number(date.slice(0, 4))).get(date);
}
```

import type { Status } from './labels';

/** タイムラインの日付計算・グループ化（DOM 非依存）。日付はすべて 'YYYY-MM-DD'、計算は UTC。 */

export const GROUPS = ['assignee', 'milestone', 'none'] as const;
export type GroupBy = (typeof GROUPS)[number];
export const SCALES = ['day', 'week'] as const;
export type Scale = (typeof SCALES)[number];

const DAY_MS = 86_400_000;

export function addDays(date: string, n: number): string {
	return new Date(Date.parse(date) + n * DAY_MS).toISOString().slice(0, 10);
}

/** b - a（日数） */
export function diffDays(a: string, b: string): number {
	return Math.round((Date.parse(b) - Date.parse(a)) / DAY_MS);
}

/** 0 = 日曜 */
export function weekday(date: string): number {
	return new Date(date).getUTCDay();
}

export function mondayOf(date: string): string {
	return addDays(date, -((weekday(date) + 6) % 7));
}

/** 土日か祝日 */
export function isOffDay(date: string): boolean {
	const d = weekday(date);
	return d === 0 || d === 6 || holidayName(date) !== undefined;
}

/** 'M/D' */
export function shortDate(date: string): string {
	return `${Number(date.slice(5, 7))}/${Number(date.slice(8, 10))}`;
}

const SCALE_SPEC: Record<Scale, { days: number; dayWidth: number; step: number }> = {
	day: { days: 42, dayWidth: 32, step: 21 },
	week: { days: 182, dayWidth: 8, step: 91 }

	to: string;

	/** 1 日の幅（px） */
	dayWidth: number;

	step: number;

	const s = SCALE_SPEC[scale];

	return { from: start, to: addDays(start, s.days - 1), ...s };

	return addDays(mondayOf(today), -7);

	s !== null && ISO_DATE.test(s) && !Number.isNaN(Date.parse(s)) && addDays(s, 0) === s;

export function parseView(q: URLSearchParams, today: string): ViewParams {
	const pick = <T extends string>(v: string | null, all: readonly T[], d: T): T =>
		all.includes(v as T) ? (v as T) : d;
	const from = q.get('from');
	return {
		group: pick(q.get('group'), GROUPS, 'assignee'),
		scale: pick(q.get('scale'), SCALES, 'day'),
		from: mondayOf(isValidDate(from) ? from : defaultFrom(today)),
		milestone: q.get('milestone') ?? ''
	};
}

	startDate: string | null;
	dueDate: string | null;

export type BarSpan =
	| {
			kind: 'in';
			/** 0 始まりの列（両端を含む） */
			startCol: number;
			endCol: number;
			clippedStart: boolean;
			clippedEnd: boolean;
			missingStart: boolean;
			missingDue: boolean;
	  }
	| { kind: 'before' }
	| { kind: 'after' };

/** 表示範囲上のバーの位置。日付のない課題は null */
export function barSpan(item: Dated, range: ViewRange): BarSpan | null {
	const start = item.startDate ?? item.dueDate;
	const end = item.dueDate ?? item.startDate;
	if (!start || !end) return null;
	if (end < range.from) return { kind: 'before' };
	if (start > range.to) return { kind: 'after' };
	return {
		kind: 'in',
		startCol: Math.max(0, diffDays(range.from, start)),
		endCol: Math.min(range.days - 1, diffDays(range.from, end)),
		clippedStart: start < range.from,
		clippedEnd: end > range.to,
		missingStart: item.startDate === null,
		missingDue: item.dueDate === null
	};
}

export type DragMode = 'move' | 'start' | 'end';

/**
 * ドラッグ後の日付。開始日 ≦ 期限を保つ。
 * - move: ある方の日付をすべて delta 日ずらす
 * - start: 左端。開始日（なければ期限を起点に新しく開始日）を動かす。期限を超えない
 * - end: 右端。期限（なければ開始日を起点に新しく期限）を動かす。開始日を下回らない
 */
export function applyDrag(item: Dated, mode: DragMode, delta: number): Dated {
	const { startDate: s, dueDate: d } = item;
	if (mode === 'move') {
		return { startDate: s && addDays(s, delta), dueDate: d && addDays(d, delta) };
	}
	if (mode === 'start') {
		const base = s ?? d;
		if (!base) return item;
		const next = addDays(base, delta);
		return { startDate: d && next > d ? d : next, dueDate: d };
	}
	const base = d ?? s;
	if (!base) return item;
	const next = addDays(base, delta);
	return { startDate: s, dueDate: s && next < s ? s : next };
}

export interface IssueGroup<T> {
	key: string;
	/** group = 'none' のときは null（見出しを出さない） */
	label: string | null;
	releaseDate: string | null;
	done: number;
	total: number;

const byStart = (a: TimelineIssue, b: TimelineIssue) => {
	const x = a.startDate ?? a.dueDate ?? '';
	const y = b.startDate ?? b.dueDate ?? '';
	return x < y ? -1 : x > y ? 1 : a.number - b.number;
};

/** 担当者別・マイルストーン別・なし。「未割当」「マイルストーンなし」は最後。課題のないグループは出さない */
export function groupItems<T extends TimelineIssue>(
	items: T[],
	by: GroupBy,
	milestones: MilestoneRef[]
): IssueGroup<T>[] {
	const sorted = [...items].sort(byStart);
	const make = (
		key: string,
		label: string | null,
		releaseDate: string | null,
		list: T[]
	): IssueGroup<T> => ({
		key,
		label,
		releaseDate,
		done: list.filter((i) => i.status === 'done').length,
		total: list.length,
		items: list
	});
	if (by === 'none') return sorted.length ? [make('all', null, null, sorted)] : [];

	const buckets = new Map<string, T[]>();
	for (const i of sorted) {
		const k = (by === 'assignee' ? i.assigneeId : i.milestoneId) ?? 'none';
		buckets.set(k, [...(buckets.get(k) ?? []), i]);
	}
	const release = new Map(milestones.map((m) => [m.id, m.releaseDate]));
	const groups = [...buckets].map(([k, list]) => {
		if (k === 'none') {
			return make(k, by === 'assignee' ? '未割当' : 'マイルストーンなし', null, list);
		}
		const label = (by === 'assignee' ? list[0].assigneeName : list[0].milestoneName) ?? '';
		return make(k, label, by === 'milestone' ? (release.get(k) ?? null) : null, list);
	});
	return groups.sort((a, b) => {
		if (a.key === 'none' || b.key === 'none') return a.key === 'none' ? 1 : -1;
		if (by === 'milestone' && a.releaseDate !== b.releaseDate) {
			if (!a.releaseDate) return 1;
			if (!b.releaseDate) return -1;
			return a.releaseDate < b.releaseDate ? -1 : 1;
		}
		return a.label!.localeCompare(b.label!, 'ja');
	});
}

export type TimelineItem = IssueListItem & { canEdit: boolean };

/**
 * タイムライン用。日付のある課題はすべて（完了を含む）、日付のない課題は未完了のものだけ返す。
 * 表示範囲では絞らない（範囲外の課題にも行を出すため）。並べ替え・グループ化はクライアント側で行う。
 */
export async function listTimeline(
	ctx: AppContext,
	key: string,
	filters: { milestoneId?: string } = {}
): Promise<{ scheduled: TimelineItem[]; unscheduled: TimelineItem[] }> {
	const p = await requireProject(ctx, key);
	const rows = await selectIssues(ctx.db, filterConds(p, { milestoneId: filters.milestoneId }), [
		asc(issue.number)
	]);
	const items = rows.map((r) => ({
		...r,
		canEdit:
			!p.archivedAt &&
			can(ctx.actor, 'issue:edit', { reporterId: r.reporterId, assigneeId: r.assigneeId })
	}));
	return {
		scheduled: items.filter((i) => i.startDate || i.dueDate),
		unscheduled: items.filter((i) => !i.startDate && !i.dueDate && i.status !== 'done')
	};
}

import * as v from 'valibot';
import { command, query } from '$app/server';
import { remoteContext, runCommand, runQuery } from '$lib/server/remote-helpers';
import { listMilestones } from '$lib/server/services/issue-fields';
import { listTimeline, updateIssue } from '$lib/server/services/issues';

/** milestone: 絞り込むマイルストーン ID（'none' は未設定、'' は絞り込みなし） */
const TimelineRef = v.object({ key: v.string(), milestone: v.string() });

export const getTimeline = query(TimelineRef, ({ key, milestone }) => {
	const ctx = remoteContext();
	return runQuery(async () => {
		const [items, milestones] = await Promise.all([
			listTimeline(ctx, key, { milestoneId: milestone || undefined }),
			listMilestones(ctx, key)
		]);
		return { ...items, milestones };
	});
});

/** 開始日・期限を変える。'' は未設定。権限・前後関係・アーカイブの検査は updateIssue に任せる */
export const setIssueDates = command(
	v.object({
		...TimelineRef.entries,
		number: v.pipe(v.number(), v.integer()),
		startDate: v.string(),
		dueDate: v.string()
	}),
	({ key, milestone, number, startDate, dueDate }) =>
		runCommand(async () => {
			await updateIssue(remoteContext(), key, number, { startDate, dueDate });
			void getTimeline({ key, milestone }).refresh();
		})
);
```

	const timeline = $derived(await getTimeline(ref));
	const range = $derived(viewRange(view.from, view.scale));

	const scheduled = $derived(timeline.scheduled);
	const unscheduled = $derived(timeline.unscheduled);
	const groups = $derived(groupItems(scheduled, view.group, timeline.milestones));

	const GROUP_OPTIONS: [GroupBy, string][] = [
		['assignee', '担当者'],
		['milestone', 'マイルストーン'],
		['none', 'なし']
	];
	const SCALE_OPTIONS: [Scale, string][] = [
		['day', '日'],
		['week', '週']
	];

	/** 値が '' のキーはクエリから消す（既定値に戻る） */
	function setQuery(patch: Partial<Record<'group' | 'scale' | 'from' | 'milestone', string>>) {
		const url = new URL(page.url);
		for (const [k, v] of Object.entries(patch)) {
			if (v) url.searchParams.set(k, v);
			else url.searchParams.delete(k);
		}
		goto(url, { replaceState: true, keepFocus: true, noScroll: true });
	}
</script>

(b) `href` の定義の後にドラッグ処理を追加する:

```ts
	/** 'place' は未スケジュール欄からタイムラインへの配置 */
	type Drag = {
		item: T;
		mode: DragMode | 'place';
		startX: number;
		startY: number;
		x: number;
		y: number;
		delta: number;
		moved: boolean;
	};
	let drag = $state<Drag | null>(null);
	let canvas = $state<HTMLDivElement>();
	/** ドラッグ直後のクリック（リンク遷移）を 1 回だけ止める */
	let suppressClick = false;

	function begin(e: PointerEvent, item: T, mode: Drag['mode']) {
		if (!item.canEdit || !onsave || e.button !== 0) return;
		// リンクのネイティブなドラッグと文字選択を止める（click は止まらない）
		e.preventDefault();
		e.stopPropagation();
		drag = {
			item,
			mode,
			startX: e.clientX,
			startY: e.clientY,
			x: e.clientX,
			y: e.clientY,
			delta: 0,
			moved: false
		};
	}

	function move(e: PointerEvent) {
		if (!drag) return;
		const dx = e.clientX - drag.startX;
		const dy = e.clientY - drag.startY;
		drag.moved ||= Math.hypot(dx, dy) >= 4;
		drag.delta = Math.round(dx / range.dayWidth);
		drag.x = e.clientX;
		drag.y = e.clientY;
	}

	/** ポインタ位置の日付。タイムライン（見出しを含む）の外なら null */
	function dateAt(x: number, y: number): string | null {
		if (!canvas) return null;
		const r = canvas.getBoundingClientRect();
		if (y < r.top || y > r.bottom) return null;
		const col = Math.floor((x - r.left - LABEL_W) / range.dayWidth);
		return col >= 0 && col < range.days ? addDays(range.from, col) : null;
	}

	function end() {
		const d = drag;
		drag = null;
		if (!d?.moved || !onsave) return;
		suppressClick = true;
		setTimeout(() => (suppressClick = false));
		if (d.mode === 'place') {
			const date = dateAt(d.x, d.y);
			if (date) onsave(d.item, { startDate: date, dueDate: date });
		} else if (d.delta !== 0) {
			onsave(d.item, applyDrag(d.item, d.mode, d.delta));
		}
	}

	function guardClick(e: MouseEvent) {
		if (suppressClick) e.preventDefault();
	}

	/** ドラッグ中のバーは移動後の日付で描く */
	const shown = (item: T): Dated =>
		drag?.moved && drag.item.id === item.id && drag.mode !== 'place'
			? applyDrag(item, drag.mode, drag.delta)
			: item;
```

```ts
	/** 保存中の楽観的な日付（issue id → 日付）。保存が終われば消す */
	let pending = $state<Record<string, Dated>>({});
	const all = $derived(
		[...timeline.scheduled, ...timeline.unscheduled].map((i) =>
			pending[i.id] ? { ...i, ...pending[i.id] } : i
		)
	);
	const scheduled = $derived(all.filter((i) => i.startDate || i.dueDate));
	const unscheduled = $derived(all.filter((i) => !i.startDate && !i.dueDate));

	/** 400/409 は業務エラーなのでサーバーのメッセージを出し、それ以外は汎用文言にする */
	function failure(err: unknown): string {
		const { status, body } = (err ?? {}) as { status?: number; body?: { message?: string } };
		return (status === 400 || status === 409) && body?.message
			? body.message
			: 'この課題の日付は変更できません';
	}

	async function save(item: { id: string; number: number }, next: Dated) {
		pending[item.id] = next;
		try {
			// 保存と最新の再取得を 1 往復で行う（サーバー側で getTimeline を refresh）
			await setIssueDates({
				...ref,
				number: item.number,
				startDate: next.startDate ?? '',
				dueDate: next.dueDate ?? ''
			});
		} catch (err) {
			toast.error(failure(err));
			getTimeline(ref)
				.refresh()
				.catch(() => {});
		} finally {
			delete pending[item.id];
		}
	}
```

title: タイムライン
---

プロジェクトの「タイムライン」タブでは、課題を開始日から期限までのバーとして日付の上に並べます。バーをドラッグして日付を変更できます。

## 表示

- **グループ**: 「担当者」「マイルストーン」「なし」から選びます。担当者・マイルストーンでは、見出しに「完了 / 全体」の件数が出ます。
- **マイルストーン**: マイルストーンで絞り込めます。マイルストーン別に表示しているときは、リリース日に縦線が出ます。
- **表示**: 「日」（6 週間）と「週」（半年）を切り替えます。「前」「次」で表示期間を動かし、「今日」で今週の前の週からの表示に戻ります。

- 開始日か期限の片方だけが入っている課題は、1 日分のバーで表示し、入っていない側の端を点線にします。
- 表示期間の外にある課題は、行の右端の矢印ボタンでその期間へ移動できます。

## 日付の変更

- バーの中央をドラッグすると、開始日と期限を同じ日数だけずらします。
- バーの左端・右端をドラッグすると、開始日・期限をそれぞれ変更します。開始日が期限より後になることはありません。
- 日付が入っていない未完了の課題は、タイムラインの下の「未スケジュール」に並びます。タイムラインへドラッグすると、置いた日を開始日と期限に設定します。
- ドラッグ中に Esc キーを押すと取り消します。
- 日付を変更できるのは、課題を編集できる人だけです（[権限](/reference/permissions/)）。ゲストは自分が起票した課題だけ動かせます。アーカイブ済みのプロジェクトでは誰も動かせません。
